# 05. Экраны и сценарии

> Статус: черновик на согласовании · Обновлён: 2026-07-27

## 1. Принципы интерфейса

| Принцип | Что означает на практике |
| --- | --- |
| **Mobile-first** | Основной сценарий проектируется под 360 px. Десктоп — расширение, а не наоборот |
| **Пустой экран продаёт** | Ни один пустой список не показывает «нет данных». Он показывает следующее действие |
| **Никогда не врать о состоянии** | Интерфейс не пишет «отменено», пока пользователь не подтвердил. Это главный репутационный риск категории |
| **Спокойный тон** | Мы не пугаем суммами и не давим. «Спишут завтра» вместо «Внимание! Предстоящее списание!» |
| **На «ты», коротко** | «Спишут 399 ₽ 15 августа», а не «Уведомляем вас о предстоящем списании денежных средств» |
| **Цвет не единственный сигнал** | Статус всегда дублируется иконкой или текстом (`NFR-02`) |

## 2. Карта экранов

```
Публичная часть (без входа, индексируется поисковиками)
├── /                        Лендинг
├── /catalog                 Каталог сервисов
├── /catalog/[slug]          Страница сервиса + гид отмены   ← точка входа из поиска
└── /login                   Вход

Приложение (после входа)
├── /app                     Дашборд                          ← главный экран
├── /app/subscriptions       Все подписки
├── /app/subscriptions/new   Добавление
├── /app/subscriptions/[id]  Карточка подписки
│   └── /cancel              Гид отмены
├── /app/analytics           Аналитика
├── /app/notifications       Лента уведомлений
├── /app/import              Импорт (pro)
└── /app/settings            Настройки
```

## 3. Ключевой сценарий: первый запуск

Самая важная последовательность в продукте. Если пользователь не добавил хотя бы 3 подписки в первую сессию, он не вернётся.

```
Лендинг
  → «Начать» → вход через Telegram или email (без пароля)
  → Онбординг:
       Шаг 1. Базовая валюта (предзаполнено RUB, один тап «Далее»)
       Шаг 2. Сетка популярных сервисов — отмечаешь галочками, что у тебя есть
       Шаг 3. Для каждого отмеченного: тариф подставлен, нужна только дата списания
       Шаг 4. Канал напоминаний (Telegram предложен первым, он уже подключён)
  → Дашборд с заполненными данными
```

**Почему сеткой, а не по одной:** просьба добавить подписку по одной убивает онбординг. Сетка логотипов превращает ввод в узнавание — пользователь отмечает 5 сервисов за 20 секунд.

**Критерий успеха онбординга:** от первого экрана до заполненного дашборда — не более 90 секунд и не более 3 экранов ввода.

## 4. Дашборд

Отвечает на три вопроса сверху вниз, в порядке важности:

```
┌──────────────────────────────────────┐
│  В месяц        В год                │   ← Сколько я плачу
│  4 280 ₽        51 360 ₽             │
├──────────────────────────────────────┤
│  ⏳ ТРИАЛЫ                            │   ← Самое срочное, всегда выше
│  Яндекс Плюс — закончится через 2 дня│
│  [Оставить]  [Отменить]              │
├──────────────────────────────────────┤
│  БЛИЖАЙШИЕ СПИСАНИЯ                  │   ← Что спишут скоро
│  завтра    Кинопоиск       399 ₽     │
│  15 авг    Spotify      $10.99 ≈ 980 ₽│
├──────────────────────────────────────┤
│  Разбивка по категориям (график)     │   ← Где утечка
└──────────────────────────────────────┘
```

**Обязательные детали:**
- Триалы всегда выше активных подписок — у них есть дедлайн, у остальных нет.
- Кнопки действий прямо в блоке триала: решение принимается здесь, без перехода.
- Валютная подписка показывает исходную сумму **и** пересчёт. Пересчёт помечен `≈`.
- Если курс устарел (`isStale`), рядом появляется пометка «курс от 25 июля».

**Пустое состояние:** вместо пустого списка — сетка популярных сервисов из онбординга. Пользователь может начать добавлять прямо отсюда.

## 5. Сценарий отмены

Самый ответственный флоу. Здесь легче всего потерять доверие.

```
Карточка подписки → «Отменить подписку»
  ↓
Экран гида:
  ┌────────────────────────────────────────┐
  │  Отмена: Кинопоиск                     │
  │  ⚠ Доступ сохранится до 15 августа     │  ← предупреждение ДО шагов
  │                                        │
  │  1. Открой «Управление подпиской»      │
  │     [Перейти на сайт →]  ← deep link   │
  │  2. Выбери «Отключить продление»       │
  │  3. Подтверди отмену                   │
  │                                        │
  │  Инструкция проверена 12 июля 2026     │  ← дата всегда видна
  │  [Инструкция не сработала]             │
  └────────────────────────────────────────┘
  ↓  пользователь возвращается в приложение
  ┌────────────────────────────────────────┐
  │  Получилось отменить?                  │
  │  [Да]  [Нет]  [Вернусь позже]          │
  └────────────────────────────────────────┘
```

**Что происходит по каждому ответу:**

| Ответ | Действие |
| --- | --- |
| **Да** | Статус → `cancelled`, фиксируется дата окончания доступа. «Отменено. Доступ до 15 августа — успей досмотреть» |
| **Нет** | Статус не меняется. Альтернативы: поставить на паузу, напомнить через неделю, сообщить об устаревшей инструкции |
| **Вернусь позже** | Поток закрывается, создаётся напоминание |
| **Инструкция не сработала** | `reportCount++`, гид уходит в очередь на проверку, пользователю — общая инструкция и поиск |

**Три запрета в этом флоу:**
1. Не показывать «отменено» без ответа «Да».
2. Не скрывать предупреждение об оплаченном периоде — оно идёт **до** шагов, а не после.
3. Не показывать пустой экран, если гида нет: общая инструкция плюс ссылка на поиск по сервису.

## 6. Добавление подписки

```
[+ Добавить]
  ↓
Поиск по каталогу ("кинопоиск", "kinopoisk", "кинопойск" — всё находит)
  ↓
Найдено → тариф, период и категория подставлены → нужна только дата → Сохранить
Не найдено → «Добавить свой» → форма с ручным вводом
```

**Целевое время добавления из каталога — 15 секунд.** Всё, что этому мешает, пересматривается.

Переключатель «Сейчас идёт триал» открывает поле даты окончания триала и меняет статус на `trial`.

## 7. Уведомления

### Каналы и их роли

| Канал | Роль |
| --- | --- |
| **Telegram** | Основной. Бесплатный, мгновенный, высокая дочитываемость |
| **Web Push** | Для тех, кто установил PWA. На iOS требует установки на домашний экран |
| **Email** | Резервный и для недельных сводок |
| **In-app** | Всегда включён. История за 90 дней, работает даже если всё остальное выключено |

### Текст уведомления

```
Завтра спишут 399 ₽ — Кинопоиск

[Всё верно]  [Отменить подписку]  [Напомнить через день]
```

Коротко, с суммой и сервисом в первой строке, с действием прямо в сообщении. Нажатие «Отменить подписку» открывает гид, а не просто приложение.

### Защита от превращения в спам

- По умолчанию **одно** напоминание за 3 дня. Больше — только по явному выбору пользователя.
- Тихие часы 22:00–09:00: уведомление откладывается, а не отменяется.
- В каждом внешнем сообщении — ссылка на отключение этого типа уведомлений.
- Контроль метрики отписок от уведомлений: рост выше 10% — сигнал, что мы шумим.

## 8. Аналитика

| Блок | Содержание |
| --- | --- |
| Расходы по месяцам | 12 месяцев, столбчатый график |
| Разбивка по категориям | Доли, сортировка по убыванию |
| Прогноз на год | На основе активных подписок |
| Сэкономлено | Годовая стоимость отменённого через продукт — главный аргумент ценности |

На бесплатном тарифе доступны 3 месяца, глубже — заглушка с объяснением, что даёт `pro`. Заглушка показывает реальную форму данных пользователя в размытом виде, а не абстрактную рекламу.

## 9. Состояния экранов

Для каждого экрана обязательно проектируются четыре состояния. Отсутствие любого — незакрытая задача.

| Состояние | Требование |
| --- | --- |
| **Загрузка** | Скелетон по форме будущего контента, не спиннер по центру |
| **Пусто** | Объяснение и следующее действие. Никогда не «Нет данных» |
| **Ошибка** | Что случилось и что делать. Никогда не голый код ошибки |
| **Норма** | Основной сценарий |

## 10. Доступность

Требования `NFR-02`, обязательные к проверке:

- Контраст текста ≥ 4.5:1.
- Все формы работают только с клавиатуры.
- Фокус виден всегда, порядок обхода логичен.
- Статусы подписок различимы без цвета — иконка или подпись обязательны.
- Области нажатия ≥ 44×44 px.
- У иконок-кнопок есть `aria-label`.
- Уважается `prefers-reduced-motion`.

## 11. Telegram-бот

**Роль бота:** канал уведомлений и быстрых решений, а не полноценный интерфейс.

| Команда | Действие |
| --- | --- |
| `/start` | Привязка аккаунта |
| `/subs` | Список активных подписок текстом |
| `/soon` | Ближайшие списания |
| `/app` | Открыть Mini App с полным интерфейсом |

Быстрые действия в уведомлениях — inline-кнопки: «Всё верно», «Отменить», «Напомнить позже». Всё, что сложнее одного нажатия, уходит в Mini App, который переиспользует тот же веб-интерфейс.
