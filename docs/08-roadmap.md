# 08. Роадмап

> Статус: черновик на согласовании · Обновлён: 2026-07-27

## Принцип нарезки

Каждый этап заканчивается состоянием, которое **можно показать и потрогать**. Не «готов бэкенд» — это ничего не значит для пользователя. Внутри этапа порядок работ определяется зависимостями, а не удобством.

---

## M0 · Фундамент

**Результат:** пустое приложение запускается одной командой, есть вход, есть CI.

| Задача | Что входит |
| --- | --- |
| Инициализация проекта | Next.js 15, TypeScript `strict`, Tailwind, структура папок из [02-architecture.md](02-architecture.md) |
| Docker Compose | app, worker, postgres, redis — `docker compose up` поднимает всё |
| Схема БД | Prisma-схема из [03-data-model.md](03-data-model.md), первая миграция |
| Границы слоёв | `eslint-plugin-boundaries` с правилами зависимостей |
| Авторизация | Email OTP + Telegram Login, сессии, guard-функции |
| Каркас интерфейса | Layout, навигация, примитивы дизайн-системы, тёмная тема |
| CI | tsc, eslint, vitest, audit, сканер секретов |
| Локализация | Инфраструктура словарей — с первого дня, иначе строки расползутся по коду |

**Готово, когда:** можно войти через Telegram и через email и увидеть пустой дашборд. CI зелёный.

---

## M1 · Ядро продукта

**Результат:** продукт уже полезен. Можно вести подписки и видеть, куда уходят деньги.

| Задача | Что входит |
| --- | --- |
| Домен подписок | Сущность, состояния, переходы, инварианты. Чистые функции, тесты без БД |
| Расчёт дат списаний | `billing-cycle` с правилом якорного дня. Отдельный набор тестов — см. [07](07-testing-strategy.md) |
| Модуль денег | Минорные единицы, конвертация, форматирование через `Intl` |
| CRUD подписок | Создание, изменение, пауза, возобновление, мягкое удаление |
| Каталог сервисов | ~40 сервисов РФ и СНГ с тарифами, поиск с опечатками, публичные страницы |
| Дашборд | Итоги месяца и года, ближайшие списания, блок триалов сверху |
| Онбординг | Сетка популярных сервисов, цель — ≤ 90 секунд до заполненного дашборда |
| Мультивалютность | Загрузка курсов ЦБ РФ, пересчёт на отображении, пометка устаревшего курса |
| Трекер триалов | Состояние `trial`, автопереход в `active`, приоритет в интерфейсе |

**Готово, когда:** новый пользователь за 90 секунд добавляет 5 подписок и видит корректную сумму в месяц, включая валютную подписку.

**Ключевой риск этапа:** качество каталога. 40 сервисов с точными тарифами важнее, чем 200 с приблизительными.

---

## M2 · Отмена и напоминания

**Результат:** продукт начинает приносить деньги пользователю, а не просто показывать цифры.

| Задача | Что входит |
| --- | --- |
| `CancellationProvider` | Порт и реализация `GuideCancellationProvider` |
| Гиды отмены | Инструкции для сервисов каталога: шаги, deep link, предупреждения, дата проверки |
| Флоу отмены | Экран гида → вопрос «получилось?» → обработка всех четырёх исходов |
| Обратная связь по гидам | «Инструкция не сработала» → очередь на актуализацию |
| Планировщик | BullMQ, ежечасный проход, `dedupeKey`, тихие часы |
| Каналы уведомлений | Порт + четыре реализации: in-app, Telegram, Web Push, Email |
| Настройки напоминаний | Правила по типам событий, выбор каналов, тихие часы |
| Лента уведомлений | История in-app за 90 дней |
| PWA | Манифест, service worker, офлайн-просмотр, установка на домашний экран |

**Готово, когда:** пользователь получает напоминание за 3 дня, переходит по нему в гид, отменяет подписку и подтверждает результат. Повторный запуск планировщика не создаёт дублей.

**Ключевой риск этапа:** идемпотентность. Дубли уведомлений — самый быстрый способ потерять пользователя.

---

## M3 · Аналитика, Telegram-бот и тарифы

**Результат:** продукт удерживает и готов к монетизации.

| Задача | Что входит |
| --- | --- |
| Аналитика | Расходы по месяцам, категории, прогноз на год, «сэкономлено» |
| Тарифы | `free`/`pro`, фиче-флаги, серверная проверка доступа, лимит 10 подписок |
| `BillingProvider` | Порт + `NoopBillingProvider`. Всё платное разделено, оплата ещё не подключена |
| Telegram-бот | Команды, inline-кнопки в уведомлениях, привязка аккаунта |
| Telegram Mini App | Переиспользование веб-интерфейса внутри Telegram |
| Экспорт и удаление | JSON и CSV, самостоятельное удаление аккаунта (`FR-12`) |
| Импорт CSV | Первый `ImportSource`: кандидаты, подтверждение, определение дублей |
| Наблюдаемость | Структурированные логи, метрики доставки, алерт при падении ниже 95% |

**Готово, когда:** бот шлёт уведомления и открывает Mini App; бесплатный тариф упирается в лимит и видит понятное объяснение; CSV-импорт создаёт кандидатов, а не подписки.

## M4 · Публичный запуск

**Результат:** продукт доступен реальным пользователям.

| Задача | Что входит |
| --- | --- |
| Юридическая база | Политика обработки ПДн, согласия, уведомление Роскомнадзора (вопросы Q2, Q3 из [01](01-requirements.md)) |
| Продакшн-инфраструктура | Российский хостинг, домен, HTTPS, бэкапы с проверкой восстановления |
| SEO | Страницы гидов отмены, разметка, карта сайта — главный канал органического роста |
| Подключение оплаты | Реализация `BillingProvider` для YooKassa, вебхуки, чеки 54-ФЗ |
| Нагрузочная проверка | Соответствие `NFR-01` на реальных данных |
| Аудит безопасности | Проход по модели угроз из [06](06-security-privacy.md) |

**Готово, когда:** посторонний человек проходит путь от поисковой выдачи до отменённой подписки без нашей помощи.

## После запуска

Порядок определяется данными, а не планом. Кандидаты:

| Направление | Триггер для запуска работ |
| --- | --- |
| Парсинг почты | Ручной ввод остаётся барьером, ретеншн упирается в него |
| Семейный доступ | Регулярные запросы от пользователей на общие подписки |
| Синхронизация с банком | Появилось юрлицо и подтверждён спрос на автоимпорт |
| Нативные приложения | PWA упирается в ограничения платформ (в первую очередь push на iOS) |
| Автоматическая отмена | Проверена юридическая модель, найден способ без хранения чужих паролей |
| Выход за пределы РФ | Продукт стабилен, есть свободный ресурс. Здесь пригодится нейтральное имя `Subwise` |

## Что осознанно не делаем

| Соблазн | Почему отказываемся |
| --- | --- |
| Начать с банковской интеграции | Самая сложная часть с самым высоким регуляторным риском при непроверенной гипотезе |
| Сделать сразу мобильное приложение | Ревью сторов замедляет цикл; PWA проверяет спрос быстрее |
| Наполнить каталог 500 сервисами | 40 точных полезнее 500 приблизительных. Неверный тариф хуже отсутствующего |
| Подключить оплату в MVP | Требует юрлица и отвлекает от проверки главной гипотезы |
| Микросервисы «на вырост» | Нагрузки нет, а сложность появится сразу |
