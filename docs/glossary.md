# Глоссарий

> Единый словарь терминов. Термины из этого файла используются в коде **дословно** — в именах таблиц, полей, типов и функций. Если понятия нет здесь, его нельзя вводить в код: сначала добавь его сюда.

## Доменные сущности

| Термин | В коде | Значение |
| --- | --- | --- |
| Подписка | `Subscription` | Регулярный платёж пользователя за конкретный сервис. Главная сущность продукта |
| Сервис | `Service` | Запись в каталоге: Кинопоиск, Spotify, Яндекс Плюс. Справочник, общий для всех пользователей |
| Тарифный план сервиса | `ServicePlan` | Известный нам вариант тарифа сервиса: название, цена, период. Используется для автозаполнения |
| Гид отмены | `CancellationGuide` | Пошаговая инструкция отмены подписки конкретного сервиса |
| Триал | `trial` | Состояние подписки: бесплатный период с датой автоперехода в платный |
| Событие списания | `BillingEvent` | Факт или прогноз списания на конкретную дату. Основа напоминаний и аналитики |
| Кандидат на импорт | `ImportCandidate` | Предполагаемая подписка, найденная при импорте. Становится `Subscription` только после подтверждения пользователем |
| Категория | `Category` | Группировка подписок для аналитики: видео, музыка, облако, обучение |

## Состояния подписки

| Состояние | В коде | Значение |
| --- | --- | --- |
| Активна | `active` | Платная, списания идут, напоминания включены |
| Триал | `trial` | Бесплатный период, есть дата автоперехода в `active` |
| На паузе | `paused` | Учёт приостановлен пользователем: не влияет на расходы, напоминания молчат, запись сохранена |
| Отменена | `cancelled` | Пользователь подтвердил отмену. Может сохранять доступ до конца оплаченного периода |
| Истекла | `expired` | Оплаченный период закончился после отмены. Финальное состояние |

Переходы между состояниями описаны в [03-data-model.md](03-data-model.md).

## Ключевые абстракции

| Термин | В коде | Значение |
| --- | --- | --- |
| Провайдер отмены | `CancellationProvider` | Интерфейс способа отменить подписку. В MVP единственная реализация — `GuideCancellationProvider`. Позволяет добавить автоматизацию, не трогая интерфейс |
| Источник импорта | `ImportSource` | Интерфейс источника данных о подписках: CSV, почта, банк. Все возвращают `ImportCandidate[]` |
| Канал уведомлений | `NotificationChannel` | Интерфейс способа доставки: in-app, Telegram, Web Push, Email |
| Провайдер оплаты | `BillingProvider` | Интерфейс приёма платежей. В MVP — заглушка `NoopBillingProvider` |
| Провайдер входа | `AuthProvider` | Интерфейс способа авторизации: Telegram, Email OTP, в будущем — Яндекс ID и VK ID |

Общий принцип: **всё, что может измениться или иметь несколько реализаций, живёт за интерфейсом.** Экраны и бизнес-логика зависят от интерфейса, а не от конкретной реализации.

## Деньги и валюты

| Термин | В коде | Значение |
| --- | --- | --- |
| Минорные единицы | `amountMinor` | Целое число копеек или центов. **Единственный допустимый способ хранить деньги.** `float` для денег запрещён |
| Базовая валюта | `baseCurrency` | Валюта, в которой пользователь видит итоги. По умолчанию RUB |
| Исходная валюта | `currency` | Валюта, в которой реально списывает сервис. Хранится вместе с подпиской и не меняется при пересчётах |
| Курс | `ExchangeRate` | Курс на дату из источника ЦБ РФ. Пересчёт выполняется только при отображении |

## Уведомления

| Термин | В коде | Значение |
| --- | --- | --- |
| Тип события | `NotificationType` | Что произошло: скоро списание, скоро конец триала, гид устарел |
| Правило напоминания | `ReminderRule` | Настройка пользователя: за сколько дней и в какие каналы уведомлять |
| Тихие часы | `quietHours` | Интервал, в который уведомления откладываются, а не отправляются |
| Идемпотентность | — | Свойство планировщика: повторный запуск для того же события не создаёт второе уведомление |

## Тарифы

| Термин | В коде | Значение |
| --- | --- | --- |
| Бесплатный тариф | `free` | Ручной ввод, до 10 подписок, все каналы уведомлений, каталог и гиды |
| Расширенный тариф | `pro` | Импорт из всех источников, полная аналитика, экспорт, без лимита подписок |
| Фиче-флаг | `FeatureFlag` | Признак доступности функции. Проверяется **на сервере**, а не скрытием кнопки в интерфейсе |

## Бренд

| Термин | Где используется |
| --- | --- |
| **Subwise** | Техническое имя: репозиторий, пакеты, переменные окружения, имена в коде, внутренняя документация |
| **Отписка** | Публичный бренд для РФ: интерфейс, домен, Telegram-бот, маркетинговые материалы |

Правило: строка «Отписка» не должна попадать в код напрямую — только в словари локализации.

## Метрики продукта

| Термин | Значение |
| --- | --- |
| Осознанное решение | Явное действие пользователя после напоминания: «оставляю» или «отменяю». Северная метрика продукта |
