# Subwise

> Публичный бренд для РФ — **«Отписка»**

Веб-приложение для управления подписками: все подписки в одном месте, напоминание до списания, пошаговая помощь в отмене.

**Статус:** M0 — каркас проекта. Документация завершена.

## Быстрый старт

Требуется **Node.js 20.11+** и Docker.

```bash
cp .env.example .env
```

Заполни `ENCRYPTION_KEY` и `SESSION_SECRET` — сгенерировать можно так:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

Дальше:

```bash
docker compose up -d postgres redis
```

```bash
npm install && npx prisma migrate dev && npm run db:seed
```

```bash
npm run dev
```

Полная проверка перед коммитом:

```bash
npm run check
```

### База для тестов

Интеграционные тесты работают на **отдельной** базе `subwise_test` — иначе прогон набора стирал бы твои данные. Разовая подготовка:

```bash
npm run db:setup-test
```

Параметры подключения — в `.env.test`. Настоящих секретов там нет: только localhost и заведомо фиктивные ключи, поэтому файл коммитится.

## Идея за 30 секунд

Средний пользователь платит за 6–12 подписок и не помнит половину из них. Проблема не в цене, а в невидимости: подписка продлевается молча, без момента осознанного решения.

Продукт возвращает этот момент:

**Видеть** → все подписки и суммы на одном экране, в одной валюте
**Успеть** → напоминание за несколько дней до списания, а не после
**Решить** → пошаговая инструкция отмены для конкретного сервиса

Мы **не** обещаем «отменим за вас в один клик». Это честно и защищает от главного риска категории: пользователь думает, что подписка отменена, а списание проходит.

## Роадмап

| Этап | Результат |
| --- | --- |
| **M0** Фундамент | Приложение запускается одной командой, есть вход, CI зелёный |
| **M1** Ядро | Новый пользователь за 90 секунд добавляет 5 подписок и видит корректную сумму |
| **M2** Отмена и напоминания | Напоминание → гид → отмена → подтверждение. Дублей уведомлений нет |
| **M3** Аналитика, бот, тарифы | Telegram-бот, Mini App, разделение `free`/`pro`, импорт CSV |
| **M4** Запуск | Посторонний человек проходит путь от поиска до отменённой подписки |

## Разработка

Проект использует агентов с разграниченными правами — см. [.claude/agents/](.claude/agents/).

`security-auditor` и `code-reviewer` намеренно не имеют прав на запись: они находят проблемы и докладывают, но не правят код. Ревьюер, который сам чинит найденное, лишает автора обратной связи.

Правила, действующие всегда, — в [CLAUDE.md](CLAUDE.md).

## Границы продукта

**Не делаем принципиально:**
- Не храним пароли от чужих сервисов
- Не совершаем платежи от имени пользователя
- Не даём финансовых советов
- Не продаём данные и не строим рекламные профили

**Отложено:** семейный доступ, автоматическая отмена, виртуальные карты, нативные приложения.
