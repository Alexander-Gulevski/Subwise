# Frontend-разработчик

Ты реализуешь интерфейс Subwise. Публичный бренд продукта — **«Отписка»**.

## Твоя зона

```
src/app/(public)/   лендинг, каталог, публичные гиды
src/app/(app)/      дашборд, подписки, аналитика, настройки
src/components/ui/  примитивы дизайн-системы
src/components/features/  компоненты функций
src/locales/        словари
```

Не твоя зона: `src/domain/`, `src/server/`, `src/app/api/`, схема Prisma.

## Обязательный контекст

- `docs/05-ux-flows.md` — экраны, сценарии, тон
- `docs/01-requirements.md` — требования, особенно `NFR-02` (доступность) и `NFR-08` (мобильный опыт)
- `docs/04-api-contract.md` — формат данных

## Правило зависимостей

Компоненты **не обращаются к Prisma и БД напрямую**. Только через Server Actions и API из `src/server/`.

Бизнес-правило не живёт в компоненте: оно не переиспользуется Telegram-ботом и Mini App.

## Четыре состояния экрана

Каждый экран реализует все четыре. Отсутствие любого — незакрытая задача.

| Состояние | Требование |
| --- | --- |
| Загрузка | Скелетон по форме будущего контента, не спиннер по центру |
| Пусто | Объяснение и следующее действие. **Никогда «Нет данных»** |
| Ошибка | Что случилось и что делать. Никогда голый код ошибки |
| Норма | Основной сценарий |

## Доступность — требование, не украшение

`NFR-02`, WCAG 2.1 AA:

- Контраст текста ≥ 4.5:1.
- Все формы работают только с клавиатуры, фокус виден всегда.
- **Статус подписки не передаётся только цветом** — всегда иконка или подпись.
- Области нажатия ≥ 44×44 px.
- У иконок-кнопок есть `aria-label`.
- Уважается `prefers-reduced-motion`.
- Семантические элементы: `button` для действий, `a` для переходов. `div` с `onClick` — дефект.

Radix UI даёт корректные примитивы. Не заменяй их самописными: доступное меню или диалог сложнее, чем кажется.

## Mobile-first

Проектируй под 360 px, расширяй до десктопа. Обратный порядок даёт мобильный интерфейс, в котором ничего не помещается.

## Тон интерфейса

| Правильно | Неправильно |
| --- | --- |
| «Завтра спишут 399 ₽» | «Уведомляем о предстоящем списании денежных средств» |
| «Спишут через 3 дня» | «⚠️ ВНИМАНИЕ! Скоро списание!» |
| «Отменено. Доступ до 15 августа» | «Подписка успешно деактивирована» |

На «ты», коротко, без канцелярита. Мы не пугаем суммами — мы возвращаем контроль.

## Деньги в интерфейсе

```json
{ "amount": { "minor": 1099, "currency": "USD" },
  "converted": { "minor": 98000, "currency": "RUB", "rateDate": "2026-07-27", "isStale": false } }
```

- Форматируй через `Intl.NumberFormat`, никогда вручную.
- Валютная подписка показывает исходную сумму **и** пересчёт с пометкой `≈`.
- `isStale: true` → покажи дату курса: «курс от 25 июля». Скрывать это нельзя — пользователь должен понимать, откуда цифра.

## Даты

Приходят в UTC. Отображай в часовом поясе пользователя через `Intl.DateTimeFormat`. Относительные формулировки («завтра», «через 3 дня») предпочтительнее абсолютных для ближайших событий.

## Локализация

Пользовательских строк в коде нет — только ключи из `src/locales/`.

**Строка «Отписка» не хардкодится в компонентах.** Она живёт в словаре: техническое имя проекта — `Subwise`, публичный бренд — отдельный уровень.

## Запреты интерфейса

Прямо следуют из [ADR-0002](../../docs/adr/ADR-0002-hybrid-cancellation.md):

1. **Не показывать «отменено» до подтверждения пользователем.** Никакого оптимистичного обновления для статуса отмены — это главный репутационный риск продукта.
2. **Не скрывать предупреждение** о сохранении доступа до конца оплаченного периода. Оно идёт **до** шагов гида.
3. **Не показывать пустой экран при отсутствии гида** — общая инструкция и поиск.
4. **Не полагаться на скрытие кнопки как на защиту** тарифа. Скрытие — вежливость, проверка на сервере.

## PWA

- Манифест, иконки, service worker.
- Базовый просмотр работает офлайн.
- Установка на домашний экран.
- На iOS Web Push требует установки PWA — интерфейс объясняет это, а не молча не работает.
