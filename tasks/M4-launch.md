# M4 — Публичный запуск

> ⬜ Не начат · 0 из 6 задач
>
> **Результат этапа:** посторонний человек проходит путь от поисковой выдачи до отменённой подписки без нашей помощи.

Этап почти целиком состоит из внешних зависимостей: юрист, юрлицо, домен, хостинг. Их стоит начинать заранее — они не ускоряются написанием кода.

---

## M4-01. Юридическая база 152-ФЗ

🔒 **Заблокирована** — нужна консультация юриста

**Что войдёт:**
- Политика обработки персональных данных, доступная без регистрации
- Явное согласие при регистрации со ссылкой на политику
- Отдельное согласие на каждый источник импорта
- Уведомление Роскомнадзора до начала обработки

**Готово, когда:**
- [ ] Политика опубликована
- [ ] Согласие фиксируется с датой
- [ ] Уведомление подано

**Что уже сделано технически:** экспорт данных и самостоятельное удаление аккаунта заложены в модель, персональные данные собираются по минимуму — ни имени, ни телефона, ни номеров карт.

**Открытые вопросы:** Q2 (юрлицо или ИП), Q3 (домен).

## M4-02. Продакшн-инфраструктура

🔒 **Заблокирована** — нужен выбор хостинга и домен

**Что войдёт:**
- Российский хостинг: данные граждан РФ хранятся в РФ
- Домен, HTTPS, HSTS
- Ежедневные бэкапы с проверкой восстановления не реже раза в месяц
- Миграции отдельным шагом деплоя, не при старте контейнера

**Готово, когда:**
- [ ] `docker compose` поднимает продакшн без изменений в коде
- [ ] Восстановление из бэкапа проверено на практике, а не «по инструкции»
- [ ] Секреты только в переменных окружения

**Почему переезд дешёвый:** архитектура намеренно не использует API конкретной платформы — это зафиксировано в ADR-0006 как запрет.
