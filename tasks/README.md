## Как пользоваться доской

- Задача считается готовой, только когда выполнены **все** критерии из её раздела «Готово, когда».
- Статус меняется здесь и в файле этапа одновременно.
- Новая задача заводится в файле своего этапа, а в сводку попадает счётчиком.
- Если задача вскрыла проблему за своими границами — она заводится отдельной задачей, а не расширяет текущую.
