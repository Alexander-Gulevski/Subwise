## M0-01. Инициализация проекта и конфигурация

✅ **Готово**

Каркас Next.js 15 с TypeScript в строгом режиме, Tailwind, структура папок по слоям.

**Что вошло:**
- `tsconfig.json` со `strict`, `noUncheckedIndexedAccess`, `noImplicitOverride`
- Структура `src/`: `domain`, `ports`, `adapters`, `server`, `app`, `components`, `lib`, `locales`
- ESLint с `eslint-plugin-boundaries` — правило зависимостей проверяется машинно
- Запреты в линтере: `$queryRawUnsafe`, `dangerouslySetInnerHTML`, `any` в домене, импорты инфраструктуры в `domain/`

**Готово, когда:**
- [x] `npx tsc --noEmit` без ошибок
- [x] `npx eslint .` без нарушений
- [x] Нарушение границ слоёв роняет линтер

**Что вскрылось:** линтер на первом же прогоне поймал реальное нарушение — адаптер авторизации импортировал из `server/`. Правило не ослабили, переработали код: `crypto` и `rate-limit` переехали в `lib/`, для персистентности кодов появился порт `OtpStore`.

✅ **Готово**

**Что вошло:**
- `docker-compose.yml`: app, worker, postgres, redis
- `Dockerfile` многостадийный, запуск не от root
- `.env.example` со всеми переменными и пояснениями
- `src/lib/env.ts` — валидация окружения при старте через Zod
- `scripts/dev.cmd` — запуск на версии Node из `.nvmrc` без переключения глобального симлинка

**Готово, когда:**
- [x] `docker compose up -d postgres redis` поднимает базу и кэш
- [x] Неполная конфигурация роняет приложение сразу, а не через час
- [x] Текст ошибки конфигурации не содержит значений переменных

**Что вскрылось:** пустые плейсхолдеры в `.env` роняли приложение. Zod-модификатор `.optional()` пропускает только `undefined`, а `KEY=` — это пустая строка. Добавлен `optionalString()`, поведение закрыто семью тестами.

## M0-04. Доменный слой

✅ **Готово**

Ядро без единой зависимости — это и делает его тестируемым без базы и браузера.

**Что вошло:**
- `domain/money` — минорные единицы, конвертация, форматирование через `Intl`
- `domain/billing-cycle` — расчёт дат с якорным днём месяца
- `domain/subscription` — состояния, переходы, приведение стоимости к месяцу и году

**Готово, когда:**
- [x] Ни одного импорта Prisma, Next.js или React в `domain/`
- [x] Подписка от 31 января даёт 28 февраля, затем **31 марта**
- [x] `float` в денежных вычислениях отсутствует
- [x] Тесты выполняются без поднятой базы

**Ключевые решения:**
- Недели считаются по 365,25 дня, а не по 52 — разница почти в целую неделю платежей за год
- Месячная стоимость выводится из годовой, иначе «в месяц × 12» и «в год» расходятся на экране

## M0-06. Авторизация

✅ **Готово**

**Что вошло:**
- Email OTP: 6 цифр, `crypto.randomInt`, 10 минут, ≤5 попыток, 3 запроса за 15 минут
- Telegram Login с проверкой HMAC-SHA256
- Сессии: cookie `httpOnly`, в базе хеш токена
- Guard-функции: `requireUser`, `requireSubscriptionOwnership`, `requireFeature`, `requireSubscriptionQuota`
- Rate limiting на Redis

**Готово, когда:**
- [x] Паролей в системе нет вообще
- [x] Ответ на запрос кода одинаков для существующего и несуществующего аккаунта
- [x] Подмена telegram id ломает подпись
- [x] В базе хеши, а не токены и коды

**Что вскрылось:** вход через Telegram отдавал 500 `INTERNAL` при незаданном токене бота — ошибка конфигурации маскировалась под внутреннюю. Добавлен статус `unavailable` в порт и код `PROVIDER_UNAVAILABLE` (503).
