## M3-01. Аналитика расходов

⬜ **Не начата**

**Что войдёт:**
- Расходы по месяцам за 12 месяцев
- Разбивка по категориям с долями
- Прогноз на 12 месяцев вперёд
- «Сколько сэкономлено» — годовая стоимость отменённого через продукт

**Готово, когда:**
- [ ] Суммы в аналитике сходятся с суммой подписок
- [ ] Все значения в базовой валюте с явной пометкой при участии курса
- [ ] На бесплатном тарифе видны 3 месяца, глубже — объяснение

**«Сэкономлено» — главный аргумент для платного тарифа.** Без него `pro` продаётся вслепую.

## M3-07. Импорт CSV

⬜ **Не начата**

Первая реализация `ImportSource` — начинаем с неё, потому что у неё наименьшая юридическая сложность.

**Готово, когда:**
- [ ] Импорт создаёт **только** `ImportCandidate`, ни одной подписки
- [ ] Отклонённый кандидат не предлагается повторно
- [ ] Дубликаты с существующими подписками помечаются
- [ ] Требуется явное согласие с описанием, какие данные читаются
- [ ] Отзыв доступа очищает `credentialsEnc`

**Инвариант:** одна неверно созданная подписка обесценивает все цифры на дашборде. Поэтому подтверждает пользователь, всегда.
