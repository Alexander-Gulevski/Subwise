## X-05a. Локализация интерфейса

⬜ **Не начата** · найдена при чистке кода

`NFR-07` требует, чтобы пользовательских строк в коде не было — только ключи из `src/locales/`. Требование нарушено: около пятнадцати строк захардкожены в шести файлах, а одиннадцать шаблонов в словаре не используются вообще.

**Где именно:**

| Файл | Строк |
| --- | --- |
| `components/features/subscriptions/subscription-form.tsx` | 3 |
| `app/app/settings/page.tsx` | 3 |
| `app/app/page.tsx` | 3 |
| `components/features/onboarding/onboarding-flow.tsx` | 2 |
| `components/features/subscriptions/subscription-row.tsx` | 1 |
| `components/ui/button.tsx` | 3 |

**Готово, когда:**
- [ ] Ни одной русской строки в разметке компонентов
- [ ] Шаблоны словаря используются через `interpolate`
- [ ] Склонение («день/дня/дней») вынесено в отдельный помощник, а не размазано по компонентам
- [ ] Линт-правило ловит новые захардкоженные строки

**Почему не исправлено сразу:** это отдельный рефакторинг с риском задеть тексты, которые проверяются сквозными тестами по содержимому. Делать его в одном коммите с чисткой мёртвого кода — значит смешать две разные правки и усложнить разбор, если что-то сломается.
